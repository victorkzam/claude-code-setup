## §R3 Research: best practices and contrarian (researcher sonnet 2026-09-16, three angles; the rev 8.1 rows on the `cw` prefix, `@import` rules and model routing carry over unchanged)

| # | Choice | Best practice | Contrarian | Verdict |
|---|---|---|---|---|
| 1 | Lean cut for Claude 5 | Anthropic removed >80% of Claude Code's system prompt for Opus 5 and Fable 5 "with no measurable loss"; the tax is duplication and contradiction, not length; verification and self-check nudges go ("Opus 5 verifies its own work without being told"); CLAUDE.md under ~200 lines; always-rules in CLAUDE.md, on-demand procedures in skills. https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models · https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5 | Over-deletion of project gotchas that look like boilerplate; behaviour moved into judgment shifts when the model changes; a separate reviewer process is NOT what the "cut self-verification" guidance targets | Apply; keep gotchas, scope boundaries, verdict schemas; per-file cap + dedupe; round trip before publish |
| 2 | Reviewer severity | "If your review prompt says 'only report high-severity issues' … the model may follow that instruction literally and report less; ask it to report everything and filter in a separate pass" (Opus 5 guide) | — | Reviewers report everything; the orchestrator filters |
| 3 | Plugin layout and versioning | Anthropic's own plugins: `plugin.json` alone inside `.claude-plugin/`, components at the root, flat semver (`1.0.0`), no CHANGELOG files, `hooks.json` with `${CLAUDE_PLUGIN_ROOT}` and 10 s timeouts, agents mostly set `model` only. https://github.com/anthropics/claude-code/tree/main/plugins | None of the official plugins ship tests or CI (a gap, not evidence) | Follow the layout; keep `effort` and `maxTurns` (documented, cheap) |
| 4 | Self-hosted marketplace | Documented; community template Nagell/claude-marketplace-template; dual install paths documented side by side in obra/superpowers-marketplace | Plugin name equal to the marketplace name crashes installs on Linux (EXDEV, #24389); flat namespace (#45266); a second marketplace with the same name silently overwrites (#44042) | Marketplace `claude-code-setup`, plugin `cw` |
| 5 | Hook tests in plain bash; `validate` in CI | Anthropic's plugin-dev skill tests hooks with `echo '{…}' \| bash hook.sh; echo $?` (no bats); ScottHysom/claude-plugins CI installs the CLI and runs `claude plugin validate` unauthenticated on every push | No precedent for a `run.sh <subcommand>` dispatcher (bespoke; unsourced judgment) | Plain-bash runner; `validate` step in CI |
| 6 | `if:` on safety hooks | The official security-guidance plugin uses `if: Bash(git push:*)` | The doc calls `if` best-effort and points to the permission system for hard guarantees; #46056 reported chained commands skipped in earlier versions and #63066 a permissive parser fallback | No `if` on the two safety hooks; the script splits the command on shell separators and checks every segment |
| 7 | Deleting the delegate guard | Claude 5 guidance: scope boundaries suffice, remove nudges | Fable 5 overrode a persisted delegation rule repeatedly under cost pressure (#89114); a subagent ignored "surgical edits only" (#63356); Anthropic backs delegation prose with deterministic caps | The P0 probe showed `disallowed-tools` also strips the tools from subagents, so `/cw:build` keeps a prose boundary plus the review gate (accepted risk); no hook, no sentinel |
| 8 | Symlinked skills-dir loading | Documented in-place loading | Recurring issues: auto-update removes symlinks (#50052), the installer skips symlinks (#57339), `/skills` misses them (#14836), Desktop skips them (#37435), duplicate listing (#23819) | The maintainer's path (plan A links it; the alias re-links); the README documents the real-directory fallback and the marketplace path for adopters; the plugin works from any of the three |
| 9 | Single design file | `plansDirectory` puts plans beside code | Spec-driven workflows (cc-sdd, Spec-Kit derivatives) split spec/plan/tasks files; no Anthropic source prescribes either | Keep the single file (judgment call, unsourced); `/cw:build` reads both layouts |
| 10 | `disable-model-invocation` on build, ship, compound | Documented, current | None found | Keep |
| 11 | README shape | Official plugin READMEs: overview, commands, workflow, agents, requirements, troubleshooting; marketplace templates add install paths and versioning | No comparator for a "personal workflow turned template" | Add requirements, "what to adapt", the three install paths, migration from the installer, uninstall, the fragility note |
